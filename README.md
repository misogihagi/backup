# backup

デジタルデータの長期保存は、個人にとっても企業にとっても重要な課題です。HDDやSSD、クラウドストレージなど、多くの選択肢がありますが、それぞれにメリットとデメリットがあります。その中でも、**Blu-rayディスク**は、適切な方法で運用することで、非常に優れたバックアップメディアになり得ます。

本記事では、Blu-rayをバックアップとして活用するための技術的な側面、特にそのメリットとデメリット、そして実際の運用方法について解説します。


## Blu-rayバックアップのメリットとデメリット

### メリット
* **長期保存性**: Blu-rayディスク、特に**BD-R (記録型)**は、適切な環境で保管すれば数十年単位でのデータ保持が可能です。これは、磁気記録であるHDDや、セルへの電子の書き込みに依存するSSDよりも優れた特性です。
* **物理的な独立性**: バックアップデータがネットワークやPCから完全に切り離されるため、ランサムウェアやウイルス感染、サイバー攻撃からデータを守ることができます。
* **低コスト**: 1枚あたりの単価が安く、GBあたりのコストパフォーマンスに優れています。特に大容量のBD-R XL (100GB) を活用すれば、HDDに比べて非常に安価にデータをアーカイブできます。
* **耐環境性**: ほこりや軽い傷に強く、適切なケースに保管すれば、日常的な物理的ダメージからデータを守ることができます。

### デメリット
* **書き込み速度**: HDDやSSDに比べて、データの書き込みに時間がかかります。大量のデータを頻繁にバックアップする用途には向きません。
* **ランダムアクセス**: 特定のファイルを探し出すためにディスク全体をスキャンする必要があり、HDDやSSDのように瞬時にアクセスすることはできません。これは、**「アーカイブ (長期保存)」**には向いていますが、**「現役のデータストレージ」**としては不向きであることを意味します。
* **容量の限界**: 1枚あたりの最大容量は128GB (BD-R QL) で、テラバイト級のデータをバックアップするには複数枚のディスクが必要になります。
* **記録の不可逆性**: BD-R (追記不可) の場合、一度書き込んだデータを消去したり、上書きしたりすることはできません。これはデータの改ざん防止には役立ちますが、柔軟な運用はできません。

## 戦略

Blu-rayバックアップを成功させるためには、単にデータを書き込むだけでは不十分です。以下の手順とポイントを守ることで、その信頼性を最大限に引き出すことができます。

### 1. データは書き込む前に整理と圧縮を行っておく

バックアップする前に、不要なファイルを削除し、データを整理しましょう。その後、7-ZipやRARなどの圧縮ツールを使ってデータを1つのアーカイブファイルにまとめることをお勧めします。これにより、ディスクへの書き込みが効率化され、ディスク容量を節約できます。

### 2. 正しく書き込まれたかチェックする

バックアップそのものを行ったあとは必ずデータが書き込まれているかチェックしましょう。
**「ベリファイ」**機能つきのライティングソフトウェアを使うのも手です。これにより、書き込みエラーによるデータの破損を防ぐことができます。

### 3. 3-2-1ルールに従う

3-2-1ルールとは
* データは少なくとも「3つ」持つ
* コピーを「2つ」の異なる媒体に保存する
*「1つ」のバックアップをオフサイトに保管する
の3つを運用として守りましょうというルールです。(https://lto.co.jp/hpgen/HPB/entries/37.html)

`データは少なくとも「3つ」持つ`はBlu-ray以外にもHDDやSSDなどといったバックアップ媒体で補うこととして、
`コピーを「2つ」の異なる媒体に保存する`と`「1つ」のバックアップをオフサイトに保管する`が、ここで重要となることになります。

そのルールに従うなら
* Blu-rayメディアはバックアップ1つにつき、2つ用意し、
* 一つは手元へ、もう一つは遠方に保管
ということが考えられます。

### 4. 定期的なデータ検証

データは時間の経過とともに劣化する可能性があります。数年ごとにバックアップしたディスクをPCで読み込み、データが正常に読み出せるかを確認しましょう。これを怠ると、いざという時にデータが使えないという最悪の事態になりかねません。

## 具体的なバックアップ手順

Blu-rayでの具体的なバックアップ手順は、主に**準備**、**書き込み**、**保管**の3つのステップに分けられます。最も重要なのは、データが確実に書き込まれ、長期的に読み出し可能であることを確認することです。

---

### 1. 準備段階

**データの整理と圧縮**
バックアップするデータを選別し、不要なファイルは削除します。その後、**7-Zip**や**WinRAR**といった圧縮ソフトを使って、複数のファイルを1つのアーカイブファイルにまとめます。これにより、ディスクへの書き込みが効率化し、ディスク容量を節約できます。

**必要な機材とソフトウェア**
* **Blu-rayドライブ**：PCに内蔵または外付けのBlu-rayドライブが必要です。
* **Blu-rayディスク**：データバックアップには、追記不可でデータ改ざんの心配がない**BD-R**が適しています。長期保存を目的とするなら、耐光性や耐熱性に優れる「M-DISC」の利用も検討しましょう。
* **ライティングソフトウェア**：Windows標準機能でも書き込みは可能ですが、エラーチェック機能である**ベリファイ**機能を持つ専用ソフトの使用を強く推奨します。**ImgBurn**や**BurnAware Free**などが代表的なベリファイ機能付きの無料ソフトです。

**Blu-rayディスクの容量**

* **BD-R (Single Layer)**: 25GB
* **BD-R DL (Dual Layer)**: 50GB
* **BD-R TL (Triple Layer)**: 100GB
* **BD-R QL (Quad Layer)**: 128GB

これらはBD-R（追記型）の場合の最大容量です。BD-RE（書き換え型）も同様の容量がありますが、BD-Rの方が長期保存に向いています。

さらに詳しく言うと、以下のとおりです。
ディスクの仕様（1GB＝1,000,000,000バイト）として計算した場合の数値です。

* **128GB（4層）**: **128,000,000,000 バイト**（約1,280億バイト）
* **100GB（3層）**: **100,000,000,000 バイト**（約1,000億バイト）
* **50GB（2層）**: **50,000,000,000 バイト**（約500億バイト）
* **25GB（1層）**: **25,000,000,000 バイト**（約250億バイト）

パソコン（OS）は「1GB＝1,024MB（1,073,741,824バイト）」として計算するため、パソコンに挿したときにプロパティ等で表示される実際の最大容量は、これよりも少し少なく（目減りして）見えます。

* **25GBディスク**の場合：パソコン上では約 **23.2 GB**（約 26,843,545,600 バイト）
* **50GBディスク**の場合：パソコン上では約 **46.5 GB**
* **100GBディスク**の場合：パソコン上では約 **93.1 GB**
* **128GBディスク**の場合：パソコン上では約 **119.2 GB**

ファイル管理システム（UDFなど）のオーバーヘッド（管理領域）も消費されるため、実際にファイルを書き込める限界は、パソコン上の表示値からさらに数％少なくなります。

### 2. 書き込み手順

#### 1. バックアップしたいファイルをまとめる

バックアップしたいファイルをまとめるために、`7z`コマンドを使って1つのアーカイブファイルを作成します。このときどのようなファイルシステムを使うかわからないのでFAT32でも大丈夫なように最大で`4GiB-1`になるよう分割します。

```bash
7z a -mx9 -mrr5% archive.7z backup_folder -v4095m # 4GB(4096MB)より低くする
```

このとき確認用のハッシュリストも作っておきます。

```bash
shasum backup.part* > backup.hashlist
```

#### 2. ISOイメージファイルの作成

次に、mkisofsコマンドを使って、アーカイブファイルから書き込み用のISOイメージファイルを作成します。

```bash
mkisofs -V "backup" -J -r -o backup.iso backup.*
``

#### 3. Blu-rayディスクをドライブに挿入

**Blu-rayディスクをドライブに挿入**し、PCに認識させます。今回はここでマウントされたデバイスファイルを`/dev/sr0`とします。お使いの環境によって異なる場合がありますので、lsblkコマンドなどで確認してください。


#### 4. Blu-rayディスクへの書き込み

最後に、growisofsコマンドを使ってISOイメージをBlu-rayディスクに書き込みます。このコマンドは、書き込みとベリファイ（データ検証）を同時に行うことができます。

```bash
growisofs -dvd-compat -Z /dev/sr0=backup.iso
```

* -Z : 新しいセッションを開始し、ISOイメージを書き込みます。
* backup.iso : 書き込むISOイメージファイルです。

#### 5. 書き込まれたファイルの確認

ベリファイも信用ならないときがあります。やっぱり手動でも動かすのが一番です。
さっき取ったハッシュリストを使いましょう・

書き込まれたBlu-rayをマウントし、マウント先で
```bash
shasum backup.part* > /tmp/backup2.hashlist
diff backup.hashlist /tmp/backup2.hashlist
```
とすると正常に書き込まれていれば、`backup.hashlist`が差分として出るはずです。

#### 注意事項

* デバイスファイルの確認 : 必ずlsblkなどでドライブのデバイスファイル名を確認してください。間違えると別のデバイスに書き込んでしまう可能性があります。

* 書き込み速度 : コマンドにdvd-compatを付けることで、一部のオプションが無効になる場合があります。速度を明示的に指定したい場合は-speed=4のようにオプションを追加できますが、低速での書き込みを強く推奨します。

* エラー処理 : コマンド実行中にエラーが発生した場合、ディスクが使えなくなる可能性があります。エラーメッセージを確認し、原因を特定することが重要です。

### 3. 保管と管理

**ディスクの物理的な保護**
* **専用ケースに保管**：ディスクは裸のままにせず、物理的な衝撃や傷から守るため、専用のプラスチックケース（ジュエルケースなど）に1枚ずつ保管します。不織布ケースは、ディスク表面に傷をつける可能性があるため非推奨です。
* **垂直に保管**：ディスクを平積みにすると、重みでディスクが歪む可能性があるため、本棚のように立てて保管するのが理想的です。

**環境管理**
* **適切な温度と湿度**：ディスクは高温多湿や直射日光に弱いため、**温度10～25℃、湿度40～60%**の冷暗所で保管しましょう。
* **定期的なデータ検証**：Blu-rayは長期保存性に優れていますが、永久ではありません。数年おきにディスクを読み出して、データが正常に読み出せるか確認する「データ検証」を定期的に行いましょう。

これらの手順を遵守することで、Blu-rayディスクを信頼性の高いバックアップメディアとして活用できます。

## まとめ

Blu-rayは、その**長期保存性**と**物理的な独立性**という特性から、**「コールドストレージ (長期保管用データ)」**のバックアップとして非常に優れた選択肢です。頻繁な更新が必要なデータには向きませんが、写真や動画、重要な書類など、一度アーカイブすればあまり変更しないデータのバックアップには最適です。

HDDやクラウドサービスといった他のバックアップ方法と組み合わせることで、**「HDDには直近のデータを、Blu-rayには長期保存したいデータを」**といった形で、より強固なデータ保護体制を構築することができます。

デジタル化が進む現代において、物理的なバックアップの重要性は増しています。この機会に、Blu-rayを活用したバックアップ戦略を検討してみてはいかがでしょうか。
